2Qué cambió hoy

Portada del inicio

Se cambió por una con casos reales de antes y después, para que el paciente vea resultados desde el primer momento.

Seguros

Se agregó un buscador con 24 aseguradoras, para que el paciente sepa rápido si aceptan su seguro.

Contacto

Se agregaron un letrero de bienvenida y un mapa que se abre desde una moneda, para que el paciente encuentre cómo llegar.

Cierre de cada página

Se agregó la ciudad de Las Vegas con un letrero de neón del logo, para cerrar la visita con la identidad local de la clínica.

Además

  • Formulario de citas con revisión de cada dato, para que lleguen completos.
  • Botones de pausa, volver arriba y WhatsApp, para moverse más fácil.
  • Todo ajustado para celular.
